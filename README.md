# SHOX-AKE-BANK-STRATEGIYASI-INDICATORI
Shoh Ake Bank Strategy v1 Pro is an advanced Pine Script v5 indicator for TradingView. Created by SARVEX (Sarvarbek Salimov), it features smart liquidity sweeps, ATR/Fixed Stop Loss, multi-TP targets (1:1, 1:2, 1:3), displacement filters, and a real-time dashboard.
